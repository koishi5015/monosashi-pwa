# ものさし

判断を記録して、自分の評価基準を取り出すための PWA。

2案を見比べて選ぶ、一箇所だけ直すとしたらどこかを答える、どちらが伸びたかを当てる。
その記録を溜めて、自分が何を良いと判断しているかを後から言語化するための道具です。

## 考え方

- **答え合わせがない限り、上がるのは自信であって精度ではない。**
  正解のある問題（劣化版の判別 / 伸びた方の予測）と、正解のない問題（好みの比較）はモードを分けています
- **判定は送信した時点でロックされ、正解はそのあとで出る。**
  後出しだと「自分もそう思っていた」に吸収されて、学習がゼロになります
- **連続記録は数えません。** 記録を切らさないための判断が混ざると、データの質が落ちます
- **迷い度を必ず記録します。** 明白な優劣の比較には情報がなく、僅差で選んだ事例だけが評価の軸を分離します

## 動かす

ビルド不要。静的ファイルだけで動きます。

```bash
python3 -m http.server 5173
```

判断データは端末の IndexedDB にのみ保存され、どこにも送信されません。
設定画面から JSON / CSV で書き出せます。

## 素材

`data/items.json` は `tools/build_items.py`（非公開）で生成しています。
外部素材の結果データ（Hacker News のスコア、はてなブックマーク数、note のスキ数、YouTube の再生数）は
すべて公式APIまたは実ページで確認した実測値です。推測値は含めていません。

保持しているのはタイトル・URL・数値のみで、本文は保存していません。
